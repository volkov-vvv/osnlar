# Платформа Основание

Сайт и CRM центра повышения квалификации и профессиональной подготовки «Основание». Публичная часть показывает программы и принимает заявки. Внутренние кабинеты ведут заявки, заказы, организации и справочники.

**Инструкция для пользователей** (роли, модули, сценарии): [docs/README.md](docs/README.md).

## Роли

| Роль | Префикс | Что доступно |
| --- | --- | --- |
| Гость | `/` | Каталог курсов и формы |
| Администратор | `/admin` | Полная CRM |
| Специалист КЦ | `/cc` | Заявки, организации, заказы, статусы, ссылки |
| Агент | `/agent` | Сводка и отчёт |
| Пользователь | `/user` | Документы по заказу |

Константы ролей: `User::ROLE_ADMIN`, `ROLE_AGENT`, `ROLE_CONTACT`, `ROLE_USER` в `app/Models/User.php`. Самостоятельная регистрация отключена: учётные записи создаёт администратор или поток заказа на обучение.

## Публичный сайт

- Главная, курсы, коммерческие программы, будущие наборы, биоэкономика, архив.
- Страницы «О нас», услуги, видео, гид, карта сайта.
- Заявка на обучение (`/lid/create`), заявка организации и отдельная форма для биоэкономики (`/org`).
- Заказ на платный курс (`/order/create/{course}`).
- Yandex SmartCaptcha на форме заявки. Включение и выключение — в настройках форм админки.

## Админка

Дашборд, пользователи, компании, сведения «О нас» и документы, курсы, авторы, категории, уровни образования, регионы, ссылки, агенты, статусы, заявки и коммерческие заявки, заявки организаций, заказы, отчёты.

В разделе «Настройки»: справочник годов и параметры форм (в том числе капча). У курса можно задать статус заявки по умолчанию. Списки заявок и отчёты выгружаются в Excel.

## Контакт-центр, агент, пользователь

- **КЦ** работает с теми же заявками, организациями, заказами, статусами и ссылками, без справочников курсов и пользователей.
- **Агент** видит свою главную и отчёт.
- **Пользователь** открывает кабинет и загружает документы по заказу.

Профиль (`/profile`) общий для авторизованных ролей: имя, фамилия и аватар редактируются, email и телефон только показываются.

## Интеграции

- **ЮKassa** — создание платежа и callback.
- **MAX** — входящий вебхук бота.
- **Telegram (Telegraph)** — уведомления сотрудникам о новых заявках, если у пользователя задан чат.
- Почта, журнал активности, согласие на cookie.

## Стек

PHP 8.3+, Laravel 13, MySQL, Laravel Mix. Админка собрана на AdminLTE.

Маршруты разложены по зонам: `routes/web.php` и `routes/web/{public,admin,cc,agent,user}.php`.

## Локальный запуск

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
npm install
npm run dev
php artisan serve
```

Помимо базы и почты для полного сценария нужны:

- `YANDEX_SMARTCAPTCHA_KEY` — серверный ключ проверки капчи
- `YOOKASSA_SHOP_UD`, `YOOKASSA_SECRET_KEY` — оплаты
- `MAX_BOT_TOKEN` — бот MAX (`MAX_API_URL` по умолчанию `https://platform-api.max.ru`)

Файлы пользователей (аватар) отдаются из `storage`: после настройки диска выполните `php artisan storage:link`.
