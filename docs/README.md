# Инструкция для пользователей платформы «Основание»

Документация для людей, которые работают в системе: администраторов, специалистов КЦ, агентов, слушателей (личный кабинет) и гостей сайта.

Технический обзор для разработчиков — в корневом [README.md](../README.md).

В разделах есть **скриншоты** интерфейса; файлы лежат в [`docs/images/`](images/).

## Как пользоваться этой инструкцией

1. Начните с [ролей и входа](00-roles-and-login.md) — кто куда попадает после входа.
2. Дальше открывайте **модуль**, с которым работаете (раздел меню).
3. Если задача сквозная (несколько экранов подряд) — смотрите **сценарий** в `flows/`.

Каждый модуль построен одинаково: зачем раздел → кому доступен → пошаговые действия → типичные ошибки.

## Роли (кратко)

| Роль | Куда попадаете после входа | Что делаете |
| --- | --- | --- |
| Гость | Сайт `/` | Смотрите курсы, оставляете заявку / заказ |
| Администратор | `/admin` | Полная CRM: справочники, курсы, группы, заявки, настройки |
| Специалист КЦ | `/cc/lid` | Заявки слушателей, заказы, заявки организаций, статусы, ссылки |
| Агент | `/agent/report` | Дашборд и свой отчёт |
| Пользователь (слушатель) | `/user` | Личный кабинет: профиль и документы по заказу |

Подробнее: [Роли и вход](00-roles-and-login.md).

## Как дополняем (итерации)

Пишем по одному модулю или сценарию за раз. После черновика правим формулировки «как принято у вас» и отмечаем статус в таблице выше.

Рекомендуемый порядок следующих итераций:

1. ~~Курсы + учебные группы + заявки БИО + сценарий биоэкономики~~  
2. ~~Заявки / организации / заказы (админ + КЦ)~~  
3. ~~Публичный сайт и ЛК слушателя~~  
4. ~~Авторы, договоры, справочники, настройки~~  
5. ~~Агент, отчёты и пользователи CRM~~  

Каркас инструкции собран. Дальше — правки формулировок «как принято у вас», скриншоты и при необходимости отдельные узкие сценарии.  

## Соглашения в тексте

- Пути меню пишем как в интерфейсе: **Админка → Учебные группы**.
- Шаги нумеруем; предусловия отдельным блоком в начале сценария.
- Если действие доступно не всем ролям — это указано в начале раздела.
