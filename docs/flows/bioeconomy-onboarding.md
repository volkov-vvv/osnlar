# Сценарий: запуск курса по биоэкономике

Сквозной флоу от настройки курса до появления слушателя в учебной группе. Участники: **администратор** (настройка и контроль) и **гость** (заявка на сайте). Дальше слушатель работает в ЛК как **пользователь**.

## Цель

Новый (или существующий) курс биоэкономики принимает личные заявки: создаётся учётка, слушатель попадает в нужную группу, при необходимости получает письма.

## Предусловия

- В справочниках есть компания (и при необходимости статусы, год).
- На стенде настроена отправка почты, если нужны письма.
- По желанию в **Настройки → Биоэкономика** загружены документы для публичной страницы.

---

## Часть A. Администратор настраивает поток

### 1. Создать или открыть курс

1. **Курсы** → создать или редактировать.

![Курсы в админке](../images/admin/courses-index.png)

2. Заполните название, описание, компанию и прочие поля.
3. Включите **Открыть запись на обучение** (если приём уже идёт).
4. Включите **Биоэкономика**.
5. Сохраните курс (если создаёте новый — без сохранения группы в автоматизации ещё не выбрать).

Подробнее: [Курсы](../modules/courses.md).

### 2. Создать учебную группу

1. **Учебные группы** → создать.

![Создание учебной группы](../images/admin/studygroups-create.png)

2. Укажите названия, **обязательно выберите этот курс**.
3. При необходимости задайте даты обучения.
4. Сохраните.

Подробнее: [Учебные группы](../modules/study-groups.md).

### 3. Включить автоматизацию в курсе

1. Снова **Курсы** → этот курс → редактировать.

![Автоматизация заявок БИО в карточке курса](../images/admin/courses-edit-biolid.png)

2. В блоке автоматизации:
   - выберите **Учебная группа для заявок**;
   - включите **Создавать пользователя**;
   - при необходимости — письмо «заявка принята» и/или письмо с логином и паролем.
3. Сохраните.

Проверка: в селекте группы видна только что созданная группа. Если нет — вернитесь к шагу 2 и проверьте привязку курса.

---

## Часть B. Гость подаёт личную заявку

1. На сайте откройте раздел биоэкономики (`/bioeconomy`).

![Раздел биоэкономики на сайте](../images/public/bioeconomy-index.png)

2. Выберите курс → форма личной заявки (`/lid/bioeconomy/{course}`).

![Личная форма заявки БИО](../images/public/biolid-personal-create.png)

3. Заполните и отправьте форму.

**Не путать** с формой заявки **организации** (`/org/bioeconomy`): она создаёт заявку организации, а не запись в **Заявках по БИО**, и автоматика группы/пользователя курса к ней не применяется.

---

## Часть C. Что должно получиться

После успешной личной заявки (при полной автоматизации):

| Ожидание | Где смотреть |
| --- | --- |
| Заявка в списке | **Заявки по БИО** |
| Пользователь с ролью слушателя | Карточка заявки → ссылка на пользователя; или **Пользователи** |
| Слушатель в группе | **Учебные группы** → карточка группы → список пользователей |
| Письма | Почта заявителя (если опции включены) |

![Список заявок по БИО](../images/admin/biolids-index.png)

![Карточка заявки БИО](../images/admin/biolids-show.png)

Если что-то из цепочки не сработало — заявка всё равно должна быть в списке; доделайте вручную:

1. В карточке заявки — **Создать учётную запись**.
2. В списке БИО — **Создать пользователей** с выбором группы (для набора заявок).
3. **Отправить письмо** (по одной заявке или массово) — когда учётка уже есть.

Подробнее: [Заявки по БИО](../modules/biolids.md).

---

## Часть D. Дальше по процессу (кратко)

1. Слушатель входит в ЛК (`/user`) и загружает документы.
2. Администратор в карточке заявки БИО проверяет данные и документы (принять / отклонить с причиной).
3. При необходимости меняет статус заявки и ответственного (редактирование заявки).

Детали ЛК слушателя: [Личный кабинет](../modules/user-cabinet.md).

---

## Чек-лист «почему не сработало»

| Симптом | Что проверить |
| --- | --- |
| Заявки нет в БИО | Личная ли это форма курса, а не org; курс с флагом биоэкономики |
| Нет пользователя | В курсе включено «Создавать пользователя»; в заявке указан email |
| Нет в группе | В курсе выбрана группа **этого** курса на момент заявки |
| Нет письма | Опции писем в курсе; почтовые настройки сервера |
| Группы нет в селекте курса | У группы в поле «Курс» указан этот курс |

---

## Краткая схема

```text
Курс (Биоэкономика + запись)
    → Учебная группа (course_id = этот курс)
        → В курсе: группа + создавать пользователя (+ письма)
            → Гость: личная заявка /bioeconomy/{course}
                → Заявка БИО + пользователь + группа (+ письма)
                    → ЛК: документы → проверка в карточке БИО
```
